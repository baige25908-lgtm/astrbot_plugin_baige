# 白鸽·一体（astrbot_plugin_baige）

一个插件塞进一整套"有人味"的 QQ 机器人能力：**会学梗、会配图、会自我复盘、能自愈、能记账、能查余额**，
外加群聊的唤醒闸门与节流。原本是 9 个独立插件，合并成一个包，插件列表干净、钩子顺序可控。

> 适配 AstrBot 4.29+ / Python 3.12。

## 功能

| 模块 | 做什么 |
|---|---|
| **学梗** | 每 2 小时抓 B 站热门+热评、抖音热榜、群聊高频片段、一言动画台词，提炼热梗/语气卡入库；每日一次自我复盘，生成"我哪里像 AI"的修正项，下轮注入 |
| **看图兜底** | QQ 图床 rkey 失效（HTTP 400）时照样能看见图：先走 NapCat `get_image`，再按 URL 里的 md5 去 QQ 缓存目录找同名文件，最后取最近唯一新增的那张；纯插件实现，升级 AstrBot 不会丢 |
| **配图** | 回复时 45% 概率按情绪配一张表情图；群友发的图自动收库，每 2 小时网上补货（体积/格式/尺寸/Pillow 校验 + 坏词过滤）；可选镜像到 `astrbot_plugin_angel_smile` 贴纸库（默认关） |
| **闸门** | 群聊唤醒词 / @ 才回；个人节流 + 全群节流；"安静一会儿"静默开关；主人指令；群历史裁剪；掉线补拉 |
| **体检** | 每 10 分钟自检：核心补丁是否还在、更新目录可读、组件心跳、内存、素材库体积；异常私聊主人 |
| **账本** | 记录每次 LLM 调用的输入/缓存/输出 token，每天出报表（含缓存命中率、按小时分布） |
| **余额** | QQ 里发 `/余额` 查 DeepSeek 余额；低余额可自动暂停学习 |
| **分寸** | 按你回消息的速度自适应主动频率：回得慢就少发，秒回就恢复 |
| **运维** | 受控 flag 通道（默认关）：重启 QQ / 重启核心 / 导出登录状态 |
| **自更新** | 从 `_updates` 同步插件代码（默认关，白名单限定本插件，旧版备份在插件数据目录） |

## 安装

1. **插件市场**：AstrBot WebUI → 插件 → 市场，搜「白鸽·一体」；
2. **上传安装**：把本仓库打包成 zip（根目录直接是 `metadata.yaml` + `main.py`），WebUI → 插件 → 安装；
3. **本仓库**：WebUI → 插件 → 从仓库安装，填 `repo` 地址。

安装后在 插件 → 配置 里填 `owner_qq`（主人 QQ）、`qq_account`（机器人 QQ），其余留默认即可。

依赖：仅标准库 + `aiohttp`、`Pillow`（AstrBot 自带）。

## 安全默认（重要）

所有"会碰插件目录以外东西"的能力**默认全部关闭**，需要你明确打开：

| 面板开关（安全与运维开关） | 默认 | 打开后才会 |
|---|---|---|
| 把报表/flag 写到 bridge_dir | 关 | 报表写到 `/stage` 之类的外部目录（关着时全部写在本插件数据目录） |
| 允许从 _updates 自动同步 | 关 | 每 60 秒整体替换 `data/plugins/<白名单插件>` 的代码 |
| 允许运维 flag 通道 | 关 | 监听 `bridge_dir/ops/*.flag`，能结束 QQ 进程、用面板 token 重启核心 |
| 允许主人运维指令 | 关 | QQ 里的「重载 / 重启 / 部署 / 配置」；「状态 / 撤回 / 帮助」不受影响 |
| 允许读写其他插件数据 | 关 | 往天使之笑贴纸库镜像、读 stealer 图库、改 emotion_core 配置、写 mimo TTS 数据库 |
| 允许读取宿主 cmd_config.json | 关 | 从宿主 LLM 配置里取 DeepSeek key（更推荐直接填 `deepseek_api_key`） |
| 清理历史旧插件目录 | 关 | 删除本插件自己的旧版本目录（一次性迁移用） |

另有一处**只读**访问：看图兜底会按 md5 在 NapCat/QQ 自己的图片缓存目录里找同名文件
（不写、不删、不修改），这是图床 rkey 失效时救命的那一步。

默认安装下：只读写自己的 `data/plugin_data/astrbot_plugin_baige/`，不发外部请求（
学梗/补货/余额这几项本来就是显式联网功能，可在面板里关）。

## 配置

- 群聊闸门/节流/归档：面板「安全与运维开关」之外的 13 个分组（面板值为准，
  留空的字符串回退到 `data/config/fish_core_config.json`）。
- 其余模块用默认值即可；`/余额` 需要 AstrBot 里已配置 `deepseek` provider。

## 数据目录

```
data/plugin_data/astrbot_plugin_baige/
  vibe/    梗库、台词库、复盘记录（sqlite）
  media/   表情库、使用记录
  health/  体检状态
  meter/   用量账本（sqlite）
  balance/ 余额状态
  attach/  自适应状态
  fish/    节流/静默/补拉状态
  reports/ 各类报表（token/余额/体检/梗库快照），打开桥接开关后才写到外部目录
  backups/ 插件与配置备份
```
