# 白鸽·一体（astrbot_plugin_baige）

一个插件塞进一整套"有人味"的 QQ 机器人能力：**会学梗、会配图、会自我复盘、能自愈、能记账、能查余额**，
外加群聊的唤醒闸门与节流。原本是 9 个独立插件，合并成一个包，插件列表干净、钩子顺序可控。

> 适配 AstrBot 4.29+ / Python 3.12。

## 功能

| 模块 | 做什么 |
|---|---|
| **学梗** | 每 2 小时抓 B 站热门+热评、抖音热榜、群聊高频片段、一言动画台词，提炼热梗/语气卡入库；每日一次自我复盘，生成"我哪里像 AI"的修正项，下轮注入 |
| **配图** | 回复时 45% 概率按情绪配一张表情图；群友发的图自动收库，每 2 小时网上补货（体积/格式/尺寸/Pillow 校验 + 坏词过滤）；同步到 `astrbot_plugin_angel_smile` 贴纸库 |
| **闸门** | 群聊唤醒词 / @ 才回；个人节流 + 全群节流；"安静一会儿"静默开关；主人指令；群历史裁剪；掉线补拉 |
| **体检** | 每 10 分钟自检：核心补丁是否还在、更新目录可读、组件心跳、内存、素材库体积；异常私聊主人 |
| **账本** | 记录每次 LLM 调用的输入/缓存/输出 token，每天出报表（含缓存命中率、按小时分布） |
| **余额** | QQ 里发 `/余额` 查 DeepSeek 余额；低余额可自动暂停学习 |
| **分寸** | 按你回消息的速度自适应主动频率：回得慢就少发，秒回就恢复 |
| **运维** | `/stage/ops/*.flag` 触发重启 QQ / 重启核心 / 导出登录状态 |
| **自更新** | 每 60 秒扫 `/stage/_updates`，编译校验通过才替换，旧版备份到 `plugin_data/dsh_backups/` |

## 安装

1. **插件市场**：AstrBot WebUI → 插件 → 市场，搜「白鸽·一体」；
2. **上传安装**：把本仓库打包成 zip（根目录直接是 `metadata.yaml` + `main.py`），WebUI → 插件 → 安装；
3. **本仓库**：WebUI → 插件 → 从仓库安装，填 `repo` 地址。

安装后在 插件 → 配置 里填 `owner_qq`（主人 QQ）、`qq_account`（机器人 QQ），其余留默认即可。

依赖：仅标准库 + `aiohttp`、`Pillow`（AstrBot 自带）。

## 配置

- 群聊闸门/节流/归档：沿用 `data/config/fish_core_config.json`（56 项）。
- 其余模块用默认值即可；`/余额` 需要 AstrBot 里已配置 `deepseek` provider。

## 数据目录

```
data/plugin_data/astrbot_plugin_baige/
  vibe/    梗库、台词库、复盘记录（sqlite）
  media/   表情库、使用记录
  health/  体检状态
  meter/   用量账本（sqlite）
  balance/ 余额状态
  attach/  自适应状态
  fish/    节流/静默/补拉状态
```
